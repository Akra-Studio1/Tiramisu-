# ТИРАМИСУ | Жаркент — сайт

Готовый статический сайт без сборки: просто загрузить папку на GitHub Pages / Netlify / любой хостинг.

## Что внутри
| Файл | Что это |
|---|---|
| `index.html` | Сайт (интро с латте-артом, меню, корзина, заказ, галерея, контакты) |
| `styles.css` | Дизайн |
| `app.js` | Логика: корзина, WhatsApp, поиск, фильтры, анимации |
| `i18n.js` | Все тексты интерфейса на русском и казахском |
| `config.js` | Номер WhatsApp, ссылки на Google Таблицу и соцсети |
| `data.js` | Запасное меню (используется, пока таблица не подключена) |
| `sheets/*.csv` | Шаблоны листов для Google Таблицы: `menu`, `settings`, `gallery` |
| `privacy.html`, `offer.html` | Политика конфиденциальности и оферта (жёлтые поля заполнить) |
| `vendor/anime.min.js` | Библиотека анимаций Anime.js 3.2.2 (MIT) |

## 1. Google Таблица — чтобы хозяин сам менял цены с телефона
1. Откройте sheets.google.com → «Пустая таблица».
2. Создайте 3 листа с названиями: `menu`, `settings`, `gallery`.
3. На каждый лист: Файл → Импорт → Загрузить → выберите соответствующий файл из папки `sheets/` → «Заменить текущий лист».
4. Файл → Поделиться → **Опубликовать в интернете** → выберите лист `menu` → формат **CSV** → «Опубликовать». Скопируйте ссылку.
5. Повторите для `settings` и `gallery`.
6. Вставьте 3 ссылки в `config.js` → `sheets: { menu: '...', settings: '...', gallery: '...' }`.
7. Готово. Изменения в таблице появляются на сайте примерно через 1–5 минут (так работает публикация Google).

### Как заполнять лист `menu`
- `cat_ru` / `cat_kz` — категория. **Новая категория** = просто новое название; она сама появится в меню и навигации.
- `price` — цена числом без пробелов (`1800`). `0` = «по договорённости».
- `from` — `да`, если цена «от».
- `options` — размеры тортов: `1 кг=8000; 1.5 кг=12000; 2 кг=16000`.
- `image` — ссылка на фото, начинается с `https://` (или `images/имя.jpg`, если файл лежит в папке `images/` на сайте).
- `available` — `нет`, если товара временно нет (карточка станет серой, кнопка выключится).
- Строку удалили → товар исчез. Добавили → появился. `id` должен быть уникальным (t9, b9, …).

### Лист `settings`
`instagram`, `telegram` — ссылки (пусто = кнопка скрыта). `address_ru/kz`, `hours_ru/kz` — адрес и график (пусто = «уточняйте в WhatsApp»).
`map` — ссылка для встраивания карты (Google Maps → Поделиться → Встраивание → взять адрес из `src="..."`). `delivery` — `да`/`нет`.
`story_ru/kz` — короткая история заведения для раздела «О нас». `hero_image` — главное фото на первом экране (можно добавить строку).

### Лист `gallery`
`cat`: `desserts`, `bakery`, `cakes`, `drinks`, `interior`. `image` — ссылка на фото.

### Где хранить фото
Проще всего — положить в папку `images/` рядом с сайтом (через GitHub: Add file → Upload files) и писать в таблице `images/tiramisu.jpg`.
Размер: ~1200 px по ширине, JPG/WebP до 300 КБ.

## 2. Публикация на GitHub Pages (бесплатно)
1. github.com → New repository → имя, например `tiramisu-zharkent` → Public → Create.
2. «uploading an existing file» → перетащите **все файлы и папки** сайта → Commit.
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `/root` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/tiramisu-zharkent/`.
5. Свой домен (по желанию): купить домен (например на ps.kz / hoster.kz, ~5–7 тыс. ₸/год) → Settings → Pages → Custom domain → в DNS домена добавить записи, которые покажет GitHub. HTTPS включится автоматически (галочка «Enforce HTTPS»).

- Реальные цены и веса тортов (сейчас ориентировочные).
